# Security

If you find a security problem in this project or on https://galileo.spacecone.dev, please report it
privately rather than in a public issue: use **Report a vulnerability** on the repository's
**Security** tab. You should get a reply within a few days.

The site is a static app with no accounts or server-side code, so the most likely issues are in the
security headers (`public/_headers`), the build and data-refresh workflows, or the dependencies.
